# Security

Skills are instructions that an AI agent follows in your repository. Read a skill before you install it.

## Report a vulnerability

Do not open a public issue.

Use [private vulnerability reporting](https://github.com/heplonhq/skills/security/advisories/new) or send an email to hello@heplon.com.

Include the name of the skill, the steps to reproduce the problem and the effect. We reply in 3 business days.

## Scope

- A skill that tells the agent to do a destructive or unsafe action.
- A skill that sends code, secrets or data out of the repository.
- A script in this repository that runs unsafe commands.
